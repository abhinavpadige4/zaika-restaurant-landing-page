# Zaika Indian Restaurant Landing Page

A beautiful, responsive landing page for Zaika Indian Restaurant featuring a rich red and gold theme, complete with menu sections, chef profiles, testimonials, and a functional booking form.

## Features

- **Hero Section**: Eye-catching introduction with tagline and call-to-action buttons
- **Menu Section**: Grid layout showcasing dishes with prices and descriptions
- **About Chefs**: Profiles of talented chefs with photos and bios
- **Testimonials**: Customer reviews with star ratings and auto-slider
- **Booking Form**: Functional reservation form with client-side validation
- **Responsive Design**: Optimized for mobile, tablet, and desktop views
- **Rich Color Theme**: Elegant red (#C1272D) and gold (#FFD700) color scheme
- **Smooth Animations**: Interactive elements with smooth transitions
- **Accessibility**: Proper ARIA labels and semantic HTML structure

## Tech Stack

- HTML5
- CSS3 (CSS Variables, Flexbox, Grid)
- Vanilla JavaScript
- Google Fonts (Playfair Display & Lato)

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/zaika-restaurant-landing-page.git
   ```

2. Open `index.html` in your browser to view the landing page locally.

3. For development, you can use any local server (like Live Server in VS Code) to test the JavaScript functionality.

## Deployment

This site is designed to be deployed on static hosting platforms like:
- Netlify
- Vercel
- GitHub Pages
- Cloudflare Pages

Simply connect your GitHub repository to your preferred platform and deploy from the main branch.

## Customization

To customize the content:

1. **Text Content**: Edit the text in `index.html`
2. **Images**: Replace images in the `assets/images/` folder
3. **Colors**: Modify CSS variables in `css/style.css`
4. **Menu Items**: Add or remove menu items in the menu section
5. **Testimonials**: Update testimonial content in the testimonials section
